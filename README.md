# Tachkila V2 — Atlas FC

Application de gestion d'équipe en HTML, CSS et JavaScript (modules ES6).
Les données sont enregistrées dans le `localStorage` du navigateur.

## Pages

- `index.html` : effectif (ajouter, modifier, supprimer, capitaine, recherche, filtre, pagination)
- `pages/composition.html` : composition 4-4-2
- `pages/matches.html` : matchs et scores

## Lancer le projet avec Live Server

Les modules ES6 ne fonctionnent pas en ouvrant le fichier directement : il faut un serveur local.

1. Ouvrir le dossier `tachkila-v2` dans VS Code.
2. Installer l'extension **Live Server** (si ce n'est pas déjà fait).
3. Faire un clic droit sur `index.html`, puis **Open with Live Server**.
4. Le navigateur s'ouvre. Utiliser le menu en haut pour changer de page.

## Remarque

Une connexion internet est nécessaire pour charger le script Tailwind présent dans les pages HTML (comme dans la V1).
